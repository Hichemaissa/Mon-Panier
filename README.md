# Mon Panier Informatique — متجر حواسيب تجريبي

## الهوية
اسم المتجر: Mon Panier Informatique، الهوية البصرية: برتقالي + خلفيات داكنة.

## التشغيل
افتح ملف `index.html` مباشرة في Chrome أو أي متصفح حديث. يعمل دون خادم أو إعدادات.

## الأقسام
1. لابتوبات
2. حواسيب مكتبية
3. إكسسوارات

## الميزات
- تصميم عربي RTL، متجاوب مع الهاتف والحاسوب.
- البحث، فلترة حسب القسم، الترتيب حسب السعر والاسم.
- سلة مشتريات، تعديل الكمية، المفضلة، عرض تفاصيل المنتج.
- طلب عبر WhatsApp بعد تحديد رقم المتجر في ⚙️ الإعدادات.
- إضافة منتجات تجريبية محليًا من نافذة الإعدادات.
- بيانات السلة والمفضلة والإعدادات محفوظة في متصفح الزائر بـ localStorage فقط.

## مهم جدًا قبل النشر التجاري
- المنتجات والأسعار **أمثلة فقط** وليست مخزونًا أو عروض بيع حقيقية.
- يجب تعيين رقم واتساب المتجر، واستبدال بيانات المنتجات والصور والأسعار.
- إضافة المنتجات من الإعدادات تعمل محليًا على جهاز واحد فقط؛ **ليست لوحة إدارة متصلة بقاعدة بيانات**.
- المتجر لا يحتوي على دفع إلكتروني أو نظام مخزون أو حسابات عملاء أو لوحة مدير آمنة.
- ربط قاعدة بيانات وإدارة مخزون ودفع/طلبات يحتاج Backend واستضافة آمنة.

## التخصيص
يمكن تعديل اسم Mon Panier Informatique والنصوص والألوان داخل `index.html`.
المنتجات الافتراضية موجودة في مصفوفة `STARTER_PRODUCTS` داخل قسم JavaScript.

## الاستضافة
يمكن رفع `index.html` على خدمة استضافة صفحات ثابتة (Netlify, Cloudflare Pages, GitHub Pages)، بعد استبدال المحتوى التجريبي.

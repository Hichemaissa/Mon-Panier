Configuration requise

Créez un projet Supabase puis exécutez supabase/schema.sql dans le SQL Editor. Renseignez l'URL et la clé publique anon dans supabase/config.js, créez votre compte dans Authentication, puis ajoutez l'ID de l'utilisateur dans public.admin_users. Ne publiez jamais la clé service_role.
